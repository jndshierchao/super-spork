**申请条件：**

- 年满18岁
- 需要身份证验证

**如何添加：**
1. 申请Google AdSense账号
2. 获取你的 `publisher ID` (格式: `ca-pub-xxxxx`)
3. 替换 `index.html` 中的 `YOUR_PUBLISHER_ID`
4. 创建广告位后替换 `YOUR_AD_SLOT`

## 🚀 部署上线

### 方式1: GitHub Pages (免费) ✅ 已配置
```bash
# 推送到GitHub后自动部署
git push origin main
# 访问 https://jndshierchao.github.io/super-spork/
```

### 方式2: Vercel (免费)
```bash
# 安装Vercel CLI
npm i -g vercel

# 部署
vercel
```

### 方式3: Netlify (免费)
1. 注册 Netlify
2. 拖拽文件夹到部署区域
3. 自动部署

## 🔧 本地开发

```bash
# 克隆仓库
git clone https://github.com/jndshierchao/super-spork.git

# 进入目录
cd super-spork

# 直接用浏览器打开 index.html
# 或使用本地服务器
python -m http.server 8000
```
