## 变现方式

### 1. Google AdSense 广告
申请地址：https://www.google.com/adsense

**申请条件：**
- 网站上线并有一定内容
- 年满18岁
- 需要身份证验证

**如何添加：**
1. 申请Google AdSense账号
2. 获取你的 `publisher ID` (格式: `ca-pub-xxxxx`)
3. 替换 `index.html` 中的 `YOUR_PUBLISHER_ID`
4. 创建广告位后替换 `YOUR_AD_SLOT`

## 部署上线

### 方式1: GitHub Pages (免费)
```bash
# 1. 创建GitHub仓库
git init
git add .
git commit -m "Initial commit"

# 2. 推送到GitHub
git remote add origin https://github.com/你的用户名/ai-tools.git
git push -u origin main

# 3. 在GitHub设置中启用Pages
# Settings -> Pages -> 选择 main branch -> Save
```

### 方式2: Vercel (免费)
```bash
# 安装Vercel CLI
npm i -g vercel

# 部署
vercel
```

### 方式3: Netlify (免费)
1. 注册 Netlify
2. 拖拽文件夹到部署区域
3. 自动部署
